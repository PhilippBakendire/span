# Span on GitHub Pages

Upload index.html and .nojekyll to your repository root. Open Settings → Pages → Deploy from a branch → main → /(root) → Save. No build step is needed.

Start with an empty calendar and your six subjects. Plans save in the current browser; use Backup & preferences to export a copy or transfer devices.

https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
